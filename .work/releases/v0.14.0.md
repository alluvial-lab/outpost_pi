## Delivered outcomes

- **MCP push-turn delivery and delivery-mode generalization (`feat-mcp-push-turn-delivery`)** — Generalized `pi-extension/skills/agent-network/SKILL.md`, `mesh_server.ts` instructions, `pi-extension/README.md`, `PROTOCOL.md`, `docs/DECISIONS.md`, and the Claude mesh tutorial around push-delivered vs. inbox-drained delivery modes and the hybrid local-push / remote-inbox invariant. Added opt-in `--push-deliver` on `outpost-pi claude` (fail-fast exit 1 for both `--push-deliver` and ambient `OUTPOST_PI_MCP_PUSH_DELIVER=1` without `--outpost-mesh-wake`, preserving authority/drain/local-only guards) and `--push-deliver` / `OUTPOST_PI_MCP_PUSH_DELIVER=1` on `mesh_server.ts`, backed by `PushDeliveryTransport` and `createPushDeliveryCoordinator` (dedicated bounded 1,000-message / 4 MiB `pushQueue`, 5s `WakeGate` rate cap, 64 KiB UTF-8 burst batching, single-flight FIFO delivery, oversized-envelope and transport-failure rollback to `get_messages`, and synchronous `dispose()` teardown). Recorded settled Part 2b Antigravity (`agy` 1.5.12) clean-environment probe findings and Slice 2 architecture in `pi-extension/docs/agy-push-delivery.md` (follow-ups parked in `.work/backlog/idea-agy-push-turn-delivery.md` and `.work/backlog/idea-broker-cwd-control-char-sanitization.md`).
- **Distinguishable app↔relay outbound-mailbox saturation closes (`story-app-channel-saturation-drops`)** — Relay now emits a dedicated WebSocket close (`1013` + `relay_outbound_mailbox_saturated`, bounded by a 1s send timeout) when a client's outbound mailbox saturates, and the Flutter app projects that exact close frame into `serverCloseFrame` / `transportBackpressure` diagnostics instead of generic protocol failures. (Does not claim to resolve the separate active/blocked `story-fix-connection-metronome-death` investigation.)
- **Local mesh broker rendezvous generations (`story-mesh-broker-generation-split`)** — Eliminated multi-generation local mesh broker partitions during mass restart sweeps via unique `broker-<generation>.sock` targets, atomic `broker.sock` symlink rendezvous publication, supersession dissolution, and single-flight make-before-break `SessionPeer` failover (with disposal guards for `leave()` racing `joinOrLead()` or handshake).
- **Enforced `re` UUID-only contract and loud `invalid_envelope` NACK (`story-re-uuid-contract`)** — Validated `re` (`null` or UUID via single-source `UUID_RE`) fail-fast at both `agent_send` send surfaces (Pi extension tool and MCP server) and added loud `invalid_envelope` NACK + bounded audit logging in the local broker so malformed envelopes fail fast instead of timing out silently.
- **Name-scoped MCP endpoint lock ownership & coexistence (`story-mcp-endpoint-lock-ownership`)** — Moved the MCP mesh endpoint onto `(cwd, name)`-scoped lock acquisition (`acquireUniqueNamedCwdLock`) with restart-race grace before `#N` suffixing, in-channel contention warnings, actionable `degradedReason`, and a bounded shutdown exit timer, retiring the single-endpoint-per-folder `OUTPOST_PI_MCP_CWD` workaround.
- **Restart-loop fresh-start path and loud relaunch diagnostics (`story-restart-loop-fresh-start-loud-relaunch`)** — Added an explicit `--fresh-first` (`PI_RESTART_FRESH=1`) path to `scripts/pi-restart-loop.sh` so skill/package changes reach sessions without mobile `/new`, plus persistent lifecycle logs and `RELAUNCH-FAILED-FAST` failure traces.
- **Repository substrate & tooling** — Migrated `.work/` from `agile-workflow` to Workbench v0.26.13 (`3a62eb501`) with `scripts/validate-work.py` preserving local gitignored `.work/session-notes/`, and unified `pnpm@11.9.0` via `packageManager` pins across `pi-extension`, `site`, `protocol`, and CI.

## Compatibility and operational notes

- **Safe deploy order:** `relay` → full Pi restart → `app` sideload → operator UAT.
- **ESM reload boundary (`pi-extension`):** `/reload` in Pi does not re-import ESM `dist/`; a full Pi process restart is required to load rebuilt extension code. Newly spawned `outpost-pi claude` / `mesh_server.js` processes pick up the rebuilt `dist/` immediately.
- **CLI opt-in invariant:** `outpost-pi claude --push-deliver` (and ambient `OUTPOST_PI_MCP_PUSH_DELIVER=1` under `outpost-pi claude`) strictly requires `--outpost-mesh-wake` and exits 1 fail-fast without it.
- **Exclusions:** Dormant `cockpit/` and active/blocked `story-fix-connection-metronome-death` are excluded from `v0.14.0`.
