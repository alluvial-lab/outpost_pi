Outpost-Pi — typography options

Two faces for one world. Each option shows: alphabet · wordmark lockup with the enlarged locked mark · scale ladder · UI sample in Phosphor Beacon colors · body copy in the product's voice. Sibling identities avoided by design (Patchbay: IBM Plex · SNC: Source Sans 3 / Newsreader / Saira / Archivo / Fragment Mono).

Locked so far — world: Phosphor Beacon (dark #0D1210 native / light #F3F6F3 · accent #74CC9C / #256E47) · mark: Constellation III, enlarged ~20% (block-cursor hub + two peers). This page's lockups are the first render of the enlarged geometry — confirm the size reads right alongside type.

Option 1 — Console Mono Space Mono · mono-native

The whole product speaks terminal. Space Mono's retro-technical voice (NASA-document vibes, distinctive Q, slashed zero) makes the wordmark and UI feel like one continuous command line — the app *is* a console. Body text stays mono at lighter weight; the terminal is the brand. Boldest identity commitment of the two.

Option 2 — Instrument Console Geist + Geist Mono · sans-led

A modern technical sans leads UI and prose; its matched mono carries code, labels, and the wordmark's _pi. Reads as precision instrument rather than raw terminal — friendlier to the phone-app audience while the mono accent keeps the tool credibility. Wordmark: OUTPOST in tracked caps + _pi in mono.
